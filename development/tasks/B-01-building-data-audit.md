## 목적

주변 건축물 조사에서 사용할 공식·공간 자료원을 확인하고, 여러 SHP·API 자료를 무리하게 병합하지 않으면서 건축물 단위 통합 분석을 할 수 있는 기준을 정한다.

이번 작업은 데이터 연결·정규화 구현 전의 감사 단계다. 아직 실제 코드에 새로운 건축물 API를 추가하지 않는다.

## 이번 작업에 포함하는 것

- 현재 `lt_c_spbd`·`dt_d198` 수집과 속성 결합 방식 확인
- 건축HUB 건축물대장·건축인허가·폐쇄말소 자료의 활용 가능성 조사
- 국가공간정보 건물통합정보·건물높이 자료의 활용 가능성 조사
- 자료별 geometry·속성·식별자·기준일·공간범위 비교
- QGIS GeoPackage·공간 조인·Virtual Layer 방식 설계
- 거시·중간·대지·미시 분석에 필요한 자료량 1차 분류
- 자료를 원본·정규화·관계·분석 레이어로 나누는 기준 작성

## 이번 작업에서 제외하는 것

- 새로운 API 호출 코드 구현
- 건축물 ID 자동 결합 코드 구현

- 높이·일조·그림자 시뮬레이션
