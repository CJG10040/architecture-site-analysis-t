## 목적

주변 건축물 전체를 동일한 상세도로 수집·AI에 전달하지 않고, 대지와의 거리와 분석 목적에 따라 필요한 자료량을 다르게 적용한다.

## 확정할 범위

```text
거시: 300m 초과 ~ 1,000m
중간: 100m 초과 ~ 300m
대지: 30m 초과 ~ 100m
미시: 0m ~ 30m
```

범위는 대지 중심점과 건축물 중심점의 거리 기준으로 1차 분류한다. 대지 경계와 건물 footprint의 실제 최단거리가 필요한 경우에는 후속 대지 관계 분석에서 보정한다.

## 이번 작업에 포함하는 것

- 범위별 거리 정책을 순수 함수로 정의
- 한 건축물이 여러 중첩 범위에 포함될 수 있도록 멤버십 정의
- 범위별 필수·선택 필드 정책 정의
- 거시·중간·대지·미시별 AI 입력 정책 정의
- 지도 표시 객체와 전체 분석 객체 분리 기준 정의
- 범위별 결과 저장 이름과 provenance 필드 정의
- 범위 분류 테스트 작성

## 이번 작업에서 제외하는 것

- 건축물 ID·속성 결합
- 건축HUB API 연결
- 건축물 geometry 관계 계산
- 용도·층수·높이 정규화
- AI 프롬프트 구현
- UI에서 범위별 카드를 표시하는 작업

## 범위별 자료 정책

### 거시 300m~1km

목적: 도시 건축물 분포·밀도·규모·시기 패턴 파악

필수 필드:

```text
canonical 또는 source building id
geometry 또는 centroid
footprint area
대표용도(있을 때)
층수(있을 때)
건축연도(있을 때)
자료 기준일
결합 신뢰도
```

AI 전달:

```text
격자별 건축물 수
격자별 footprint 합계
크기·층수·용도·시기 분포
분위수·누락률
대표 패턴과 예외 건물
```

개별 건축물대장 전체 원문은 전달하지 않는다.

### 중간 100m~300m

목적: 대지 주변 건축물군·빈 공간·높이·용도 관계 파악

필수 필드:

```text
building id
geometry
footprint area
centroid
대지와의 거리
대표·세부용도(있을 때)
지상·지하층수(있을 때)
높이(있을 때)
건축연도(있을 때)
자료 기준일
결합 신뢰도
```

AI 전달:

```text
전체 기본 테이블
건물군 분포
건물 사이 거리
빈 공간 후보
용도·층수·시기 관계
```

### 대지 30m~100m

목적: 대지에 직접 영향을 주는 주변 건축물 분석

필수 필드:

```text
building id
건축물관리번호·PNU·주소
full geometry
footprint area
대표·세부용도
지상·지하층수
높이
건축면적·연면적(공식값일 때)
사용승인일
허가·말소 상태
구조
대지 각 변과의 관계
모든 출처·기준일·결합 상태
```

AI 전달:

```text
인접 건축물 전체 상세 테이블
대지 방향별 관계
높이 전이
용도·시기 관계
결합 실패·충돌
```

### 미시 0m~30m

목적: 대지 경계와 건축물의 실제 접촉면·1층·입면 분석

필수 필드:

```text
대지 인접 건축물 전체 상세정보
1층 용도·출입구
창호·벽면·차양·처마
현장사진
사진 위치·시각·방향
공실·사용 흔적
현장관찰
공공자료와 현장 차이
```

공공 API만으로 1층 개방성·실제 사용·공실을 확정하지 않는다.

## 중첩 멤버십 원칙

범위는 서로 배타적인 단일 등급이 아니라 누적 분석에 사용한다.

```text
20m 건축물: micro + site + meso + macro
80m 건축물: site + meso + macro
200m 건축물: meso + macro
700m 건축물: macro
```

단, 같은 건축물의 원본을 네 번 복제하지 않고 하나의 master record를 참조한다.

## 저장·전달 정책

```text
원본 저장:
자료 전체와 원본 속성 보존

정규화 저장:
building_master 한 건물 한 레코드

파생 저장:
범위별 ID 목록·집계·관계만 저장

AI 전달:
현재 조사 범위에 필요한 필드와 집계만 전달
```
