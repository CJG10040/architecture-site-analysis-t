# 개발 관리 폴더

이 폴더는 대지해석 에이전트의 단계별 개발 계획과 진행 기록을 관리한다.

## 파일

- [`TODO.md`](./TODO.md): 전체 프로세스의 큰 틀 TODO
- [`DEVELOPMENT-GUIDE.md`](./DEVELOPMENT-GUIDE.md): 작업 순서·세부 TODO·검증·AI 분석 원칙
- `tasks/`: 작업을 시작할 때 만드는 항목별 세부 TODO

## 사용 순서

```text
1. TODO.md에서 다음 큰 항목 확인
2. development/tasks/에 세부 TODO 작성
3. 사용자 확인이 필요한 범위 확인
4. 세부 TODO 기준으로 작업
5. 테스트·실제 결과 검증
6. TODO.md 항목 체크
7. 진행 기록 작성
8. 다음 큰 항목으로 이동
```

현재 첫 번째 분야는 **주변 건축물 조사**다. 다른 조사 분야는 주변 건축물 분야의 데이터 구조·분석·AI 전환·검증이 끝난 뒤 별도로 계획한다.
