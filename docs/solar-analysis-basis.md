# 일조·일영 분석 계산 기준

일조 분석은 확정 대지 중심의 위도·경도, 한국 표준시(UTC+9), 선택한 날짜·시각을 바탕으로 태양 **방위각**과 **고도각**을 계산한다. 방위각은 진북에서 시계 방향으로, 고도각은 지평선에서 위로 측정한다는 NOAA의 정의를 따른다.[1]

| 분석 항목 | 표시 방법 | 설계 조사에서의 사용 |
|---|---|---|
| 태양 방위각 | 진북 기준 0–360° | 채광 방향·파사드·외부공간의 노출 방향 확인 |
| 태양 고도각 | 지평선 기준 ° | 낮은 고도 태양의 눈부심·긴 그림자 가능성 확인 |
| 그림자 방향 | 태양 방위의 반대 방향 | 인접 환경·진입·체류 공간에서 현장 대조할 방향 제시 |

> 이 기능은 태양의 기하학적 위치와 방향만 다룬다. 인접 건물·수목·지형·구름에 의한 실제 일조시간, 법정 일조권 또는 에너지 성능을 판정하지 않는다.
