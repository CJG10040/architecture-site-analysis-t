# API 연결·사전 자동조사 UI 검증 기록

2026-08-20에 사전 자동조사와 필지 확정 전 중심점 지형 분석을 추가한 뒤, 데스크톱과 모바일 작업대 진입 화면을 확인했다.

| 확인 범위 | 결과 |
|---|---|
| 데스크톱 진입 화면 | 랜딩 화면의 작업대 진입 제어와 기본 레이아웃이 정상적으로 표시됐다. |
| 모바일 작업대 | 대지 저장, 정확 대지 경계 그리기, 지도, 프로젝트 생성 제어가 작은 화면에서 세로로 안정적으로 배치됐다. 상단의 메뉴 아이콘도 표시됐다. |
| 필지 확정 전 분석 | 저장된 대지 중심으로 지형·일조 분석을 실행할 수 있도록 서버·UI 조건을 변경했으며, 실제 Open-Meteo 고도 표본 응답도 확인했다. |
| 자동조사 결과 | 사용자의 명시적 실행 후 수집·보류·현장 검증 항목을 한 카드에서 구분해 표시하도록 구현했다. |

> 이 화면 검증은 초기 진입·기본 작업대 상태를 대상으로 한다. 로그인된 프로젝트에서 사전 자동조사를 실행하면 공공데이터 수집 스냅샷이 프로젝트 이력에 추가된다.
