# 로컬 연속지적도 검증 기록

2026-08-19에 관리자 설정 화면을 데스크톱 폭에서 확인했다. API 설정 카드 아래에 **로컬 연속지적도 갱신** 영역이 표시되며, 최신 ZIP 업로드 제어와 구별 적재 이력 표가 함께 노출된다.

| 구 | 기준일 | 활성 필지 수 | 자동 대체 상태 |
|---|---:|---:|---|
| 동구 | 202608 | 36,502 | 활성 |
| 서구 | 202608 | 50,428 | 활성 |
| 남구 | 202608 | 59,410 | 활성 |
| 북구 | 202608 | 86,754 | 활성 |
| 광산구 | 202608 | 154,080 | 활성 |

점검 시 표는 업로드 시각, 원본 파일명 또는 보관 URL, 처리 상태와 필지 수를 제공했다. 업로드 절차는 광주 구 코드, 6자리 기준일, 19자리 PNU, Polygon/MultiPolygon, WGS84 좌표 범위 및 35MB ZIP 제한을 검증하며, 최신 기준일을 활성본으로 전환한다.

> 로컬 연속지적도는 VWorld의 장애·빈 응답·키 미등록 때 필지 후보를 찾는 조사 보조 근거다. 측량, 소유권, 인허가의 최종 증명으로 사용하지 않는다.

릴리스 검증: Vitest 14개 파일·38개 테스트와 프로덕션 빌드가 통과했다.
