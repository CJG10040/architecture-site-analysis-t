# GitHub Pages 개인용 정적 전환 설계

## 목표

이 플랫폼을 로그인·서버·DB 없이 브라우저에서만 동작하는 개인 학습·과제용 대지조사 도구로 전환한다. 조사 프로젝트와 설정은 브라우저 로컬 저장소에 저장하며, 프로젝트 전체를 JSON으로 내보내고 다시 불러올 수 있어야 한다.

## 보관 원칙

| 항목 | 정적 전환 방식 | 저장 위치 |
|---|---|---|
| 조사 프로젝트·대지 경계·관찰·수집 요약 | 브라우저 상태와 JSON 백업 | `localStorage` 및 사용자가 내보낸 파일 |
| 공공데이터·VWorld API 키 | 설정 화면에서 직접 입력 | 해당 브라우저의 `sessionStorage` 기본값 |
| OpenAI·Gemini·Anthropic 키 | 제공자 선택 뒤 직접 입력 | 해당 브라우저의 `sessionStorage` 기본값 |
| 내보낸 조사 파일 | 사용자가 직접 보관 | 다운로드 폴더 |

API 키는 소스코드·GitHub 저장소·JSON 내보내기 파일에 포함하지 않는다. 브라우저 저장소는 개인 기기에서만 사용하며, 공용 기기에서는 세션 종료 전에 키를 지운다.

## 포함 기능

정적 버전은 프로젝트 생성, 대지 주소·좌표·경계 입력, 조사 주제 선택, 수동 API 요청의 결과 기록, 현장 관찰, 설계 가설 메모, JSON 내보내기·불러오기, OpenAI·Gemini·Anthropic 선택형 AI 요청 준비를 포함한다. VWorld는 사용자가 발급·등록한 브라우저용 키를 입력한 뒤 직접 요청하는 구조로 둔다.

## 제외 또는 대체 기능

서버 데이터베이스, 사용자 로그인, 서버측 키 암호화, 서버 중계 API, 서버 S3 저장, 서버측 자동 재시도, Manus 내장 LLM은 제거한다. 기존 공공데이터 서버 어댑터는 브라우저 직접 호출이 가능한 서비스만 정적 호출로 옮기고, CORS 또는 비공개 키 제약이 있는 서비스는 결과 붙여넣기·파일 불러오기 대체 흐름을 제공한다.

## 배포

Vite 정적 빌드 결과물을 GitHub Actions로 GitHub Pages에 배포한다. Pages 도메인 생성 뒤, VWorld 개발자센터의 인증키 도메인 등록에는 실제 Pages 주소를 입력한다. GitHub Pages는 정적 파일 호스팅만 제공하므로 서버 기능을 전제로 하지 않는다.
