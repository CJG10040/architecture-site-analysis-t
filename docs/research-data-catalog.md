# 대지조사 자료 카탈로그 및 보충 구현 기준

작성일: 2026-08-25

이 문서는 현재 `architecture-site-analysis-t`에서 조사 가능한 자료와 아직 연결·검증해야 하는 자료를 구분한다. 자료가 존재한다는 이유만으로 브라우저에서 실제로 호출 가능하거나 대지에 직접 적용 가능한 것으로 표시하지 않는다.

## 초기 목표와 점검 순서

초기 목표는 **필지 확정 → 조사 주제 선택 → 필요한 자료 추천·수집 → 공간 관계 분석 → 현장 관찰 → 설계 질문·복수 가설**의 흐름이다. 화면의 `조사 가능한 자료와 보충 목록` 패널은 이 순서를 매 프로젝트마다 다시 점검한다.

| 단계 | 현재 상태 | 확인 기준 |
|---|---|---|
| 필지 확정 | 부분~사용 가능 | 사용자가 3점 이상 경계를 그리고, 가능하면 VWorld 필지 후보의 PNU를 확인 |
| 조사 주제 선택 | 사용 가능 | 기존 조사 렌즈를 하나 이상 선택 |
| 출처 있는 자료 수집 | 부분 | Open-Meteo·VWorld 필지·도시공원 중 실제 응답 또는 원본 파일 근거 저장 |
| 공간 관계 분석 | 보충 필요 | 대지와 주변 건축물·도로·시설의 거리·중첩·밀도 분석 필요 |
| 현장 검증 | 사용 가능 | 관찰 시각·위치·내용을 직접 기록 |
| 설계 전환 | 부분 | 저장된 근거·관찰을 바탕으로 AI 설계 전환을 실행하고 가설을 검토 |

## 현재 연결된 자료

| 자료 | 제공기관·서비스 | 현재 역할 | 한계 |
|---|---|---|---|
| 대지 경계·필지 후보 | VWorld 연속지적도, 사용자 지도 | 중심점 주변 필지 후보와 사용자가 그린 경계를 구분 | 중심점 기반 후보이며 측량·소유권·인허가 판단 아님 |
| 고도 표본 | Open-Meteo Elevation / Copernicus DEM | 큰 레벨 차이의 초기 표본 | DEM 격자가 옹벽·계단·정확 레벨을 대체하지 않음 |
| 대기질 표본 | Open-Meteo Air Quality | 대지 중심 격자 표본 | 대지 직접 측정값 또는 측정소 확정값 아님 |
| 도시공원 | 공공데이터포털 전국도시공원 | 공원 목록 표본 | 현재 샘플 수집이며 좌표·거리·주변성 보완 필요 |
| 현장 관찰 | 사용자 입력 | 소리·빛·냄새·체류·접근·레벨 기록 | 관찰 시각·관찰자·반복성에 영향을 받음 |
| AI 설계 전환 | 선택한 BYOK LLM | 근거를 질문·가설로 변환 | 법규·안전·인허가 판단이 아니며 사용자가 검토해야 함 |

## 우선 보충할 자료

### P0 — 대지와 직접 연결되는 공간자료

1. **건축물 footprint·대표/주요/세부 용도·층수**
   - VWorld 건축물정보와 국토교통부 용도별건물정보를 먼저 비교한다.
   - 건축HUB 건축물대장정보는 선택 건물의 상세 속성 보완용으로 검토한다.
   - `lt_c_spbd`의 footprint만으로 건물 용도를 단정하지 않는다.
   - 건물관리번호·PNU·공간 교차 기준을 확인한 뒤 대표용도와 혼합용도를 분리한다.

2. **도로 등급·유형·차로수·폭**
   - VWorld 교통링크와 ITS 표준노드링크의 `LINK_ID`, `ROAD_RANK`, `ROAD_TYPE`, `LANES`를 우선 검토한다.
   - 실제 폭 속성이 없으면 `차로수 기반 추정폭`으로 표시하고 실제 폭으로 단정하지 않는다.
   - 링크 수·폭으로 교통량을 추정하지 않는다.

3. **용도지역·지구·구역 및 행위제한**
   - VWorld 용도지역지구도와 국토교통부 토지이용규제정보서비스를 연결한다.
   - 확정 PNU와 지역·지구 코드를 결합한다.
   - 토지이음과 관할 원문을 안내하며 법규 결론을 자동 확정하지 않는다.

### P1 — 생활권과 환경 맥락

- SGIS 인구·가구·주택·연령·사업체 통계
- 버스 정류장·노선·철도·환승 및 지자체 BIS
- 복지·교육·의료·공공시설
- 공원·녹지와 하천·수계·침수·배수
- 에어코리아 측정소와 공식 측정시각
- 소음 측정자료와 시간대별 현장 기록

### P2 — 설계 해석을 풍부하게 하는 자료

- 문화시설·도서관·박물관·미술관
- 국가유산 공간정보
- 항공영상 및 시계열 변화
- 유휴·철거·신축·지역 기억에 관한 현장·지자체 자료

## 구현 원칙

- `implemented`, `partial`, `planned`, `field` 상태를 구분한다.
- `planned` 자료를 실제 수집 완료로 표시하지 않는다.
- 원본 출처·수집시각·공간 단위·갱신주기·정확도 한계를 근거 카드에 남긴다.
- 대지 자체 값, 주변 반경 값, 행정구역 통계, 측정소 값을 서로 섞지 않는다.
- 데이터 공백은 `미확인` 또는 `현장조사 필요`로 유지한다.
- AI에는 정규화된 근거와 한계만 전달하고, 근거 없는 수치·교통량·소음·법규 결론을 생성하지 않는다.
