# 지형 분석 데이터원 기록

지형 분석은 [Open-Meteo Elevation API](https://open-meteo.com/en/docs/elevation-api)를 사용한다. 이 API는 WGS84 위도·경도 좌표를 최대 100개까지 한 번에 받고, Copernicus DEM 2021 GLO-90 기반의 고도를 미터 단위 배열로 반환한다. 공개 비상업 사용 조건과 90m DEM 해상도 때문에, 본 기능은 초기 설계 조사와 대지의 큰 레벨 변화 파악에만 사용한다.

| 검증 좌표 | 반환 고도 | 확인일 |
|---|---:|---|
| 35.1467, 126.9210 | 43m | 2026-08-20 |
| 35.1470, 126.9220 | 47m | 2026-08-20 |

> DEM 표본은 현황측량, 경계측량, 배수 설계 또는 인허가용 레벨 기준을 대체하지 않는다. 경계가 작은 도심 필지에서는 개략 경사와 단면 질문을 제시하는 데 사용한다.
