# 일조·일영 분석 기능 검증 기록

2026-08-20에 데스크톱 및 모바일 폭에서 작업대의 지도, 대지 저장, 정확 대지 경계 그리기 제어가 일조·일영 분석 추가 뒤에도 안정적으로 표시되는 것을 확인했다.

일조 분석은 사용자가 조사 흐름에서 **대표일 일조 분석 실행**을 누른 경우에만 수행한다. 결과는 `solar` 분석 스냅샷으로 저장되며, 춘·추분·하지·동지의 09:00·12:00·15:00 태양 방위각·고도각과 반대 그림자 방향을 표로 제시한다. 작업대 지도에는 동지 12:00 기준 그림자 방향을 금색 점선으로 표시한다.

> 이 결과는 기하학적 태양 위치와 방향을 보여 주는 초기 설계 조사 근거다. 주변 건물·수목의 실제 차폐와 법정 일조시간, 인허가 판단은 포함하지 않는다.
