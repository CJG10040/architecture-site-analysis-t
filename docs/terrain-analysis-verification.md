# 지형 분석 기능 검증 기록

2026-08-20에 데스크톱과 모바일 폭에서 작업대의 지도·대지 저장·정확 대지 경계 그리기 제어가 지형 분석 코드 추가 뒤에도 안정적으로 표시되는 것을 확인했다.

지형 분석은 사용자가 조사 흐름에서 **경계의 지형 분석 실행**을 명시적으로 선택한 후에만 수행한다. 결과는 조사 이력에 `terrain` 스냅샷으로 저장되며, 고도 범위·평균 경사·주 하강 방향·대지 장축 11점 단면을 표시한다. 저장된 단면선은 작업대 지도에서 보라색 점선으로 나타난다.

> 분석은 약 90m 해상도의 Copernicus DEM 표본을 이용한다. 미세 레벨차와 법정·측량 기준점은 현장 측량 및 관할 자료로 대조해야 한다.
