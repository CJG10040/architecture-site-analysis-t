# 공간 맥락·현장 사진 위치 연계 검증 기록

2026-08-20에 작업대 시작 화면을 데스크톱과 모바일 폭에서 확인했다. 두 화면 모두 대지 저장, 정확 대지 경계 그리기, 분석 대지 중심 안내와 설계 전환 영역이 겹치거나 잘리지 않고 표시됐다.

필지 확정 후에는 로컬 연속지적도 도형에서 계산한 면적·둘레와 가장 긴 외곽선의 접면 후보를 제공한다. 인접 후보는 대지 중심 80m 이내의 활성 로컬 연속지적도에서 거리순으로 제공한다. 현장 자료에서 좌표가 유효한 사진은 작업대 지도에 녹색 마커·미리보기로 표시되며, 자료 카드의 **지도에서 위치 보기**로 해당 위치를 다시 열 수 있다.

> 도형 면적과 접면 후보는 초기 설계 조사를 위한 계산값이다. 도로 폭, 법정 접도, 측량·소유·인허가 판단은 현장 확인과 관할 원문 자료가 필요하다.
