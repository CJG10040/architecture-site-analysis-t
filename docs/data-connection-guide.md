# 자료 연결 방법 및 부분 구현 현황

이 문서는 설정 화면의 `자료별 발급·연결 사이트`와 함께 사용하는 사용자용 절차다. API 키·Client Secret은 채팅, GitHub, 프로젝트 JSON에 올리지 않는다.

## 1. VWorld

1. VWorld에서 회원가입·로그인한다.
2. Open API/개발자센터에서 2D Data API와 WMS/WFS 사용 키를 발급한다.
3. 키 설정의 허용 URL에는 현재 Pages 주소 또는 등록한 루트 domain을 넣는다.
4. 설정 화면의 VWorld 인증키와 허용 URL에 입력한다.
5. `연결 확인` 후 대지 화면에서 필지·건축물·도로·용도지역·생활권 자료를 수집한다.
6. `INVALID_KEY`, `INCORRECT_KEY`, `UNAVAILABLE_KEY`가 나오면 키 값은 공유하지 말고 오류 코드와 등록 domain 형식만 확인한다.

공식 사이트: https://www.vworld.kr/

## 2. 공공데이터포털

1. 공공데이터포털 회원가입·로그인한다.
2. 사용할 데이터셋에서 `활용신청`을 한다.
3. 서비스별 일반 인증키/ServiceKey와 활용 승인 상태를 확인한다.
4. 설정 화면에 ServiceKey를 입력한다.
5. `연결 확인` 후 공원·시설 등 승인된 서비스를 선택한다.
6. 브라우저 CORS 또는 서비스 미승인으로 실패하면 해당 데이터셋의 JSON·CSV·XML 원본을 내려받아 `원본 파일 가져오기`로 추가한다.

현재 직접 연결 대상 예시:

- 토지임야정보: https://www.data.go.kr/data/15123884/openapi.do
- 건축물·용도별건물정보: https://www.data.go.kr/data/15123458/openapi.do
- 용도지역지구도: https://www.data.go.kr/data/15058773/openapi.do
- 토지이용규제정보: https://www.data.go.kr/data/15058410/openapi.do
- 하천망: https://www.data.go.kr/data/15058825/openapi.do

## 3. SGIS

1. SGIS 개발자센터에서 이용신청·개발자 등록을 한다.
2. Client ID와 Client Secret을 발급한다.
3. 설정 화면 SGIS 카드에 두 값을 모두 입력한다.
4. `연결 확인`으로 인증 응답을 확인한다.
5. 대지 화면에서 SGIS 인구·가구·주택 또는 사업체 통계를 선택해 수집한다.
6. SGIS 통계는 필지 직접값이 아니라 역지오코딩된 행정구역·집계구 통계다.

공식 사이트: https://sgis.mods.go.kr/developer/html/newOpenApi/api/intro.html

## 4. NAVER 지도

1. NAVER Cloud Console에서 Maps Application을 만든다.
2. Web Dynamic Map을 활성화한다.
3. Web 서비스 URL에 Pages 주소를 등록한다.
4. Client ID를 설정 화면에 입력한다.
5. Client Secret은 정적 지도 화면에 입력하지 않는다.

공식 사이트: https://console.ncloud.com/maps

## 5. 키가 필요 없는 자료

다음 자료는 별도 API 키 없이 자동 연결을 시도한다.

- 고도·대기질: Open-Meteo
- 하천·수로·수면 표본: OpenStreetMap Overpass

OSM 수계자료는 매핑된 수로·수면 표본이다. 침수위험·배수능력·법정 하천경계를 의미하지 않는다.

## 6. ITS 교통자료

1. ITS 표준노드링크에서 표준노드·링크 원자료를 확인한다.
2. 필요한 지역의 링크 데이터와 `LINK_ID`를 확보한다.
3. 현재 VWorld 도로 링크의 `LINK_ID`와 공간 범위·갱신일을 비교한다.
4. 매칭되는 교통량 자료가 있으면 CSV/JSON으로 가져온다.
5. 매칭되지 않으면 교통량은 미확인으로 둔다.

공식 사이트: https://www.its.go.kr/nodelink/

## 7. 소음

대지 단위의 신뢰할 수 있는 소음값을 임의로 생성하지 않는다.

1. 국가소음정보시스템 또는 지자체 측정자료의 원본을 확보한다.
2. 측정일·시각·위치·기기·단위·값·날씨·활동을 확인한다.
3. 원본 CSV/JSON/TXT를 가져오거나 상세 조사에 직접 기록한다.
4. 스마트폰 측정은 공식값이 아닌 현장 참고 측정으로 표시한다.

공식 사이트: https://www.noiseinfo.or.kr/

## 8. 침수·배수

1. 국토교통부 하천망 또는 WAMIS 자료를 확인한다.
2. 지자체 침수흔적도·재해위험지도·배수구역 자료를 확인한다.
3. GeoJSON·CSV·SHP를 GeoJSON으로 변환하거나 원본을 가져온다.
4. 파일의 좌표계·기준일·위험등급·공간범위를 함께 기록한다.
5. 하천 존재만으로 침수위험을 판단하지 않는다.

공식 사이트:

- https://www.data.go.kr/data/15058825/openapi.do
- https://www.wamis.go.kr/
- https://safemap.go.kr/

## 9. 항공영상·시계열 변화

1. VWorld·지자체·공공기관에서 촬영일이 확인되는 영상을 확보한다.
2. 비교 시점과 출처를 기록한다.
3. 이미지·GeoTIFF·원본 설명 파일을 `원본 파일 가져오기`로 저장한다.
4. 신축·철거·녹지·유휴 변화는 영상 판독과 현장 확인을 구분한다.

현재 날짜가 없는 배경 항공사진만으로 과거·현재 변화를 자동 확정하지 않는다.

# 부분 구현 자료와 부족한 부분

`부분 구현`은 자료가 일부 연결되어 화면·원자료·지도 레이어에 표시되지만, 설계 판단에 바로 사용할 정도로 정규화·공간분석·현시성 검증이 끝나지 않았다는 뜻이다.

## 1. 도시공원·녹지

현재 연결: 공공데이터포털 전국도시공원 목록, 최대 1,000건 조회, 좌표 필터, 조사 반경 필터, Point 레이어.

부족한 부분:

- 좌표가 없는 공원·녹지 자료 보완
- 공원 경계 Polygon 연결
- 공원 면적·시설·운영 정보 정규화
- 공원까지의 실제 보행거리 계산
- 공원 접근성·연결성 분석
- 소규모 녹지·공터·가로녹지 수집
- 데이터 갱신일과 지역별 누락 여부 검증

## 2. 건축물 footprint·용도·층수

현재 연결: VWorld `lt_c_spbd` footprint, `dt_d198` 용도별건물정보 조회 시도, 식별자 후보 결합, Polygon 표시, footprint 면적 계산.

부족한 부분:

- footprint와 용도별건물정보의 실제 식별자 일치율 검증
- 대표용도·주용도·세부용도 완전 결합
- 지상층수·지하층수 연결
- 건축물 높이·연면적·건축면적 연결
- 건축물대장 상세정보 연결
- 다중 건축물·복합용도 처리
- 철거·신축·현존 여부 검증
- 건축물 용도별 밀도와 대지 관계 분석
- 일조·차폐·높이 관계 분석

footprint만으로 건물 용도나 실제 사용 상태를 확정하지 않는다.

## 3. 도로·교통링크

현재 연결: VWorld `lt_l_moctlink`, 도로중심선 fallback, `ROAD_RANK`, `ROAD_TYPE`, `LANES`, 실제 폭 후보, 차로수 기반 추정폭, 대지 경계와 도로 중심선 참고거리.

부족한 부분:

- 실제 도로 폭 필드의 정확한 이름·단위 검증
- 도로 경계와 도로 중심선 구분
- 법적 도로 접도 여부 판정
- 보도 폭·보행공간·횡단시설 연결
- 차량 진입 가능 여부 분석
- 교통량 API와 `LINK_ID` 매칭
- 시간대별 교통량·속도·차량 유형
- 보행량·자전거량
- 실제 보행 네트워크 기반 접근시간

현재 도로 중심선 거리는 법적 접도·도로경계·보도 폭이 아니다.

## 4. 용도지역·지구·구역

현재 연결: VWorld `LT_C_LHBLPN` 공간자료, 대지 경계 또는 조사 반경 BBOX 조회, 용도지역·지구 Polygon 표시, 속성·원자료 저장.

부족한 부분:

- 대지 경계와 용도지역 Polygon의 정확한 교차 면적 계산
- 필지별 적용 용도지역 확정
- 복수 용도지역이 겹치는 필지 처리
- 용도지역별 건폐율·용적률·높이 속성 연결
- 지구단위계획·특별계획구역 연결
- 최신 고시·변경일 확인
- 토지이음 원문과 공간자료 자동 대조
- 법정 규제 자동 판정

지도에 용도지역이 표시되어도 법규 적용이 완료된 것은 아니다.

## 5. 토지이용규제·행위제한

현재 연결: 확정 필지 PNU, 토지이음 원문 링크, 행위제한 검토 체크리스트.

부족한 부분:

- 토지이음 원문 자동 수집
- 행위제한 문장 자동 추출
- 건폐율·용적률·높이 제한 자동 정리
- 건축선·도로조건 자동 해석
- 문화재·고도·경관·재해 규제 연결
- 최신 법령·조례·고시 자동 갱신
- 복수 필지별 규제 차이 비교
- 법규 원문과 공간객체의 자동 연결
- 관할기관 확인 절차

현재는 법규를 확인할 준비까지 구현된 상태이며 인허가 가능 여부를 판정하지 않는다.

## 6. SGIS 인구·가구·주택·연령

현재 연결: SGIS 인증, 대지 중심점 역지오코딩, 행정구역 코드 확인, 2020년 통계 조회, 원응답 저장.

부족한 부분:

- 실제 통계 응답 필드의 완전한 정규화
- 인구·가구·주택·연령 항목을 표로 변환
- 시도·시군구·읍면동·집계구 단위 비교
- 2020년 이후 최신 연도 연결
- 대지 주변 여러 통계공간 단위 비교
- 통계공간과 대지 경계의 관계 계산
- 인구·가구·주택 구조에서 설계 이슈 추출
- 통계 누락·오류 응답 자동 진단

SGIS 값은 필지 직접값이 아니라 행정구역·집계구 통계다.

현재 연결: SGIS 사업체 통계, VWorld 주요상권 레이어, 상권 공간객체와 원자료.

부족한 부분:

- 업종별·규모별·종사자별 구분

- 현재 영업 여부 확인
- 폐업·신규·이전 변화 추적
- 영업시간·요일별 활동 분석
- 상권 경계와 실제 사업체 분포 비교
- 주거·상업·업무 기능 혼합 분석
- 시간대별 활동량과 현장 교차검증

등록 사업체 수는 실제 이용량이나 상권 활력을 의미하지 않는다.

현재 수계자료는 주변에 매핑된 수로·수면이 있는지를 보여주는 표본이다. 침수·배수·법정 하천구역을 자동 판정하지 않는다.

# 아직 자동 연결하지 않은 자료

## 소음

공식 대지 단위 API와 반복 측정 원본이 필요하다. 국가소음정보시스템·지자체 측정자료·현장 측정 CSV/JSON/TXT를 가져온다.

## 항공영상·시계열 변화

촬영일이 확인되는 과거·현재 영상, GeoTIFF, 이미지 원본이 필요하다. 날짜가 없는 배경 항공사진만으로 변화 여부를 자동 확정하지 않는다.

## 교통량·보행량

일반 도시도로 `LINK_ID`와 매칭되는 실제 교통량 원자료 또는 지자체 교통 API가 필요하다. 도로 폭·차로수로 교통량을 추정하지 않는다.

## 침수·배수

하천 존재만으로 침수위험을 판단할 수 없다. 공식 위험지도·침수흔적도·배수자료의 원본이 필요하다.

# 공통적으로 남은 구현 단계

부분 구현 자료를 설계 분석에 사용할 수 있는 수준으로 높이려면 다음 단계가 필요하다.

1. 원자료 응답 구조 완전 정규화
2. 필드명·단위·기준일 확정
3. 대지 경계와의 공간관계 계산
4. 여러 자료 사이의 교차분석
5. 현재성·갱신일 검증
6. 지역별 API 누락·CORS 처리
7. 지도 객체와 조사 근거의 연결
8. 설계 질문·현장조사 항목으로 변환
